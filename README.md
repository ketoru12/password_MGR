# パスワード管理アプリ

PC とスマホで同期できる、自分専用のパスワード管理 Web アプリ（PWA）です。

- **端末内で暗号化**: マスターパスワードから鍵を作り（PBKDF2-SHA256 60万回）、AES-256-GCM で暗号化してから Firebase に保存します。サイト名・ID・パスワード・メモはすべて暗号化され、サーバー側からは読めません。
- **リアルタイム同期**: PC で追加した内容がすぐスマホにも反映されます。オフライン中の編集は、次に接続したときに同期されます。
- **ワンタップでコピー**: ID / PW ボタンでコピーし、30 秒後にクリップボードを自動で消去します。
- **自動ロック**: 5 分間操作がないとき、またはアプリを裏に回して 1 分経ったときにロックします。
- **パスワード生成**: 20 文字のランダムなパスワードを作れます。

---

## セットアップ（初回のみ・15分ほど）

### 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com/ を開き、Google アカウントでログインする
2. 「プロジェクトを作成」から好きな名前で作成する（Google アナリティクスはオフで構いません）

### 2. Web アプリを登録して設定値をコピーする
1. プロジェクトのトップ画面で「</>」（ウェブ）アイコンを押す
2. アプリ名を入力して登録する（Firebase Hosting のチェックは不要）
3. 表示される `firebaseConfig = { ... }` の中身を [firebase-config.js](firebase-config.js) に貼り付ける

### 3. ログイン方法を有効にし、自分のアカウントを作る
1. 左メニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブで **メール / パスワード** を有効にする
3. 「Users」タブ →「ユーザーを追加」で、自分のメールアドレスとログイン用パスワードを登録する
   （アプリには新規登録画面を付けていないので、他人がアカウントを作ることはできません）

### 4. データベースを作り、ルールを設定する
1. 左メニュー「構築」→「Firestore Database」→「データベースの作成」
2. ロケーションは `asia-northeast1（東京）` を選び、「本番環境モード」で作成する
3. 「ルール」タブを開き、[firestore.rules](firestore.rules) の内容に置き換えて「公開」を押す

### 5. ネット上に公開する（GitHub Pages の例）
スマホから使うには HTTPS で公開する必要があります。
1. GitHub で新しいリポジトリを作成する
2. このフォルダのファイル（`.claude` フォルダ以外）をすべてアップロードする
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存する
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる
5. Firebase の Authentication →「設定」→「承認済みドメイン」に `ユーザー名.github.io` を追加する

> 公開されるのはアプリのプログラムだけです。データは本人のログインとセキュリティルールで守られ、さらに暗号化されています。

### 6. 各端末で使う
- **PC**: URL をブラウザで開く。Chrome / Edge ならアドレスバーの「インストール」でアプリとして使えます。
- **iPhone**: Safari で開く → 共有ボタン →「ホーム画面に追加」
- **Android**: Chrome で開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

初めて開いたときにマスターパスワードを設定します。2 台目以降の端末では、同じマスターパスワードでロックを解除してください。

---

## ⚠️ 注意
- **マスターパスワードを忘れると、データは二度と復元できません。** 誰も（開発者も Google も）解除できません。
- マスターパスワードは後から変更できません（誤って上書きされ全データが読めなくなる事故を防ぐため、ルールで上書きを禁止しています）。
- ログインパスワードとマスターパスワードには別のものを使うと、より安全です。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面とデザイン |
| `app.js` | 暗号化・同期・コピーなどの処理 |
| `firebase-config.js` | Firebase の接続設定（手順 2 で書き換える） |
| `firestore.rules` | データベースのアクセスルール（手順 4 で使う） |
| `sw.js`, `manifest.json`, `icon*` | ホーム画面に追加するための PWA 設定 |

## PC での動作確認
```
python -m http.server 8765
```
を実行して http://localhost:8765 を開きます（`localhost` は最初から承認済みドメインに入っています）。
